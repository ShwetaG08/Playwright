# Playwright JavaScript Practice

This repository contains JavaScript practice files for learning core concepts such as:

- Ternary operators
- Conditional statements (`if`, `switch`)
- User input and output
- Operator examples
- Number checks and comparisons

## Current content

- `chap01Basics/` - basic JavaScript examples
- `chap02JSConcept/` - core JS concept exercises

## How to run

Use Node.js from the repository root:

```bash
node chap02JSConcept/userinput.js
```
